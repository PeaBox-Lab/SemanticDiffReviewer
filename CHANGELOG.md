# Changelog

## 3.0.0 - 2026-10-19
- Added OpenAPI compatibility analysis with CI failure gates.
- Added external analyzer plugin discovery through Python entry points.
- Added a reusable composite GitHub Action.
- Added quality, CodeQL, release/PyPI, Dependabot, and enhanced automation.
- Added structured issue forms, PR template, CODEOWNERS placeholder, contribution and support policies.
- Added pre-commit configuration, architecture and rules documentation, and a fully redesigned README.
- Expanded tests and packaging metadata.

## 2.1.0 - 2026-10-19
- Added Git-aware comparison, directory/project mode, migration guides, SARIF and PR exports.
- Added rule diagnostics and baseline/drift detection.
- Preserved legacy CLI syntax while introducing workflow subcommands.

## 1.2.0 - 2026-10-19
- Added semantic policy guardrails for protected paths and change budgets.
- Added CI policy-gate workflow example.
- Added Makefile developer commands and SECURITY.md.

## 2.0.0 - 2026-10-19
- Added developer presets for APIs, Kubernetes, package manifests, strict, and human-friendly comparison.
- Added impact scoring, plain-language explanations, secret detection and report redaction.
- Added CSV and RFC 6902-style JSON Patch exports to the CLI.
- Added severity-based CI gates with `--fail-level`.
- Added stdin input support using `-`.
- Rebuilt the browser UI as SemanticDiff Studio with file loading, samples, swapping, search, impact filtering, schema status, and safer exports.
- Added `/health` endpoint and expanded tests.

## 1.1.0 - 2026-10-19
- Added JSON Schema validation, Docker, Compose, and GitHub Actions examples.
